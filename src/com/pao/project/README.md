# Sistem Gestiune Bibliotecă

### 1.1 — Acțiuni/Interogări:
1. Adaugă o carte nouă.
2. Înregistrează un cititor nou.
3. Adaugă o secțiune nouă (ex: Beletristică).
4. Împrumută o carte către un cititor.
5. Returnează o carte.
6. Caută o carte după titlu.
7. Listează toate cărțile dintr-o anumită secțiune.
8. Afișează toți cititorii ordonați alfabetic.
9. Caută un cititor după ID.
10. Șterge un cititor din sistem.

### 1.2 — Obiecte din domeniu:
`Persoana` (Abstract), `Angajat`, `Bibliotecar`, `Cititor`, `Carte`, `ISBN` (Imutabil), `Sectiune`, `Imprumut`.
